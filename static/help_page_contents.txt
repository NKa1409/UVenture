Q: How can I upload new .mzML files?A: Go to /upload_mzml_file and choose the appropriate file. Optionally add metadata that describes the file.Q: How can I create a .mzML file?A: You can create .mzML files from proprietary raw formats like .raw by using software tools such as ProteoWizard's MSConvert, which supports a wide range of vendor formats and allows conversion to the open .mzML format with customizable options for peak picking, compression, and metadata retention.Q: The tool does not find a peak at the given time although I know that there is a peak!A: Double check the settings. Be sure that you have the right setting for the time unit of the given .mzML file (either min or sec).Q: How can I start an analysis?A: Go to the homepage or /queue_new_analysis and choose the .mzML file for which you want to conduct the analysis. If the file is not uploaded to the server, upload it first. Then choose your desired type of analysis (if you choose to analyze multiple peaks, provide a peak list (mz \t rt)). Then check the corresponding checkbox and click Start.
