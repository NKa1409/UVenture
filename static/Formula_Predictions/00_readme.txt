A small part of the formula cache is given here (m/z=50 -> m/z=200) for testing and debugging purposes.
To download the whole cache as a .zip folder, please visit: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Then extract the .zip folder at the desired location.

Or create your own cache
e.g.: 
  C12H32O5,256.224975
  C12H34O4N1,256.248784
  ...
Store all formulas with the same nominal mass in one .txt file and compress it (.gz). 
Then place the file with name: formulas_for_mass_nn.txt.gz in the corresponding folder (where nn = nominal mass of the formulas).
