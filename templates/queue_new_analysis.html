U_Venture

Select the file that you want to analyze.
Then select if you want to do peak analysis or mass analysis.
If you want to do peak analysis, give the retention time and m/z.
If you want to do mass analysis, give the spectrum index and m/z.
Then click the "Upload to server" button.

The spectrum index is the index of the spectrum in the mzML file.
It can be found by viewing the file in a mzML viewer.


The server will then start the analysis. The evaluation files will be saved in the corresponding folder on the server itself.

If you don't see a file to analyze, you can upload one here.
